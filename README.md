# Age-Calculator
This web application calculates a person’s age instantly based on their date of birth. Users enter their DOB, and the system immediately displays the accurate age in years, using a simple, responsive, and user-friendly interface built with web technologies.


📌 Project Description

The Age Calculator Website is a simple and interactive web application that calculates a person’s age based on their date of birth. Users just need to enter their DOB, and the application immediately displays the accurate age in years. This project demonstrates basic frontend development concepts and JavaScript date handling.

🚀 Features

User-friendly interface

Takes Date of Birth as input

Instantly calculates and displays age

Accurate age calculation using JavaScript

Responsive and clean design

🛠️ Technologies Used

HTML – For structuring the web page

CSS – For styling and responsive layout

JavaScript – For logic, date calculation, and DOM manipulation

📂 How It Works

User selects their date of birth

JavaScript calculates the difference between the current date and DOB

The calculated age is displayed instantly on the screen

🎯 Learning Outcomes

Understanding HTML form inputs

Working with dates in JavaScript

DOM manipulation

Basic frontend project structure

🔮 Future Enhancements

Display age in years, months, and days

Add input validation

Improve UI with animations
